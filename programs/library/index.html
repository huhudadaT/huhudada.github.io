    § How to use

    Download it, then import it.

    • Download a set. It saves as a plain text file.
    • Open Flashcards, Quiz, or Fieldnotes — whichever kind the row says.
    • In its Import tab, upload the file or paste the text.

    Every file names its own kind at the top, so the row tells you which program opens it. Files under the Reference subject are the format rules themselves — hand one to an AI to get a set that imports cleanly.
