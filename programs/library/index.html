    § Using a set

    Download it, then import it.

    • Download a set. It saves as a .txt file.
    • Open Cardly for a card deck, or Quizzical for a quiz — the tag on each row says which.
    • In its Import tab, upload the file or paste the text.

    Plain text means you can edit a set in any editor first — cut what you don't need, add your own. Both apps export the same format, so whatever you build from a set goes back in. Reuse them freely: share them, rewrite them, take them somewhere else entirely.
